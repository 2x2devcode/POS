================================================================
CROSS-COMPILE WINDOWS CLI + GUI ON UBUNTU 22.04
================================================================

Build Windows executables for POSCoin from an Ubuntu 22.04 host
(also works with warnings on 24.04 / 26.04):

  - posd.exe      (headless CLI / daemon)
  - pos-qt.exe    (Qt5 GUI wallet)

Recommended: use the automated script (RNRC-style toolchain):

  chmod +x compile-windows.sh
  ./compile-windows.sh

Artifacts land in:

  release/windows/posd.exe
  release/windows/pos-qt.exe
  release/windows/logs/   (full + stage logs)

----------------------------------------------------------------
1. Host requirements
----------------------------------------------------------------

  * Ubuntu 22.04 LTS (Jammy) — primary target
  * ~20 GB free disk under the repo (depends/ + Qt)
  * Root or sudo for package installs
  * Network access (OpenSSL, Berkeley DB 4.8, Boost, Qt/MXE)

----------------------------------------------------------------
2. One-shot automated build
----------------------------------------------------------------

  ./compile-windows.sh

Environment overrides (optional):

  TARGET_ARCH=x86_64|i686   default x86_64
  BUILD_GUI=0|1             default 1 (build CLI + GUI)
  JOBS=N                    default nproc
  DEPS_DIR=/path            default ./depends/<triple>
  USE_UPNP=-                default - (UPnP off)

Examples:

  BUILD_GUI=0 ./compile-windows.sh          # CLI only
  TARGET_ARCH=i686 ./compile-windows.sh     # 32-bit Windows

The script:
  * Checks Ubuntu version
  * Installs MinGW-w64 + host packages (apt; works as root or via sudo)
  * Builds static deps into depends/<arch>-w64-mingw32/{include,lib}
      zlib, OpenSSL 3.x, Berkeley DB 4.8.30.NC, Boost 1.82, miniupnpc
  * Provisions Qt for mingw (MXE apt packages, or qtbase from source)
  * Builds posd.exe and pos-qt.exe (fully static MinGW runtime)
  * Copies binaries to release/windows/ and verifies no libstdc++/winpthread DLLs

----------------------------------------------------------------
3. Dependency layout (matches makefile.linux-mingw)
----------------------------------------------------------------

  depends/x86_64-w64-mingw32/
    include/   openssl/  db.h db_cxx.h  boost/  zlib.h  miniupnpc/
    lib/       libssl.a libcrypto.a libdb_cxx.a libboost_* libz.a ...
    src/       downloaded sources
    qt/        (only when building qtbase from source)

src/makefile.linux-mingw defaults:

  TARGET_PLATFORM=x86_64
  DEPSDIR=../depends/$(TARGET_PLATFORM)-w64-mingw32

----------------------------------------------------------------
4. Manual CLI rebuild (after deps exist)
----------------------------------------------------------------

  cd src
  make -f makefile.linux-mingw clean
  make -f makefile.linux-mingw -j$(nproc) \
    TARGET_PLATFORM=x86_64 \
    DEPSDIR=$PWD/../depends/x86_64-w64-mingw32

  Result: src/posd.exe

----------------------------------------------------------------
5. Manual GUI rebuild (after deps + mingw qmake exist)
----------------------------------------------------------------

  mkdir -p build-win-qt && cd build-win-qt
  /usr/lib/mxe/usr/bin/x86_64-w64-mingw32.static-qmake-qt5 \
    USE_UPNP=- USE_QRCODE=0 RELEASE=1 MINGW_THREAD_BUGFIX=0 \
    BOOST_LIB_SUFFIX=-mt-s-x64 \
    BOOST_THREAD_LIB_SUFFIX=-mt-s-x64 \
    BOOST_INCLUDE_PATH=$PWD/../depends/x86_64-w64-mingw32/include \
    BOOST_LIB_PATH=$PWD/../depends/x86_64-w64-mingw32/lib \
    BDB_INCLUDE_PATH=$PWD/../depends/x86_64-w64-mingw32/include \
    BDB_LIB_PATH=$PWD/../depends/x86_64-w64-mingw32/lib \
    OPENSSL_INCLUDE_PATH=$PWD/../depends/x86_64-w64-mingw32/include \
    OPENSSL_LIB_PATH=$PWD/../depends/x86_64-w64-mingw32/lib \
    "QMAKE_LFLAGS+=-static -static-libgcc -static-libstdc++" \
    ../pos-qt.pro
  make -j$(nproc)

  (Exact BOOST_*_SUFFIX is detected by compile-windows.sh from lib names.)

----------------------------------------------------------------
6. Verify outputs
----------------------------------------------------------------

  file release/windows/posd.exe release/windows/pos-qt.exe
  # PE32+ executable (console/GUI) x86-64, for MS Windows

  x86_64-w64-mingw32-objdump -p release/windows/posd.exe | grep -i 'DLL Name'
  # Must NOT list libstdc++-6.dll / libwinpthread-1.dll / libgcc_s_*.dll

----------------------------------------------------------------
7. Apt / PPA notes
----------------------------------------------------------------

  If apt update fails because a third-party PPA changed its Label:

    sudo apt-get update --allow-releaseinfo-change

  The script already passes --allow-releaseinfo-change on update.

----------------------------------------------------------------
8. Notes
----------------------------------------------------------------

  * Wallet.dat: Windows builds use Berkeley DB 4.8.30.NC (same major as
    classic Bitcoin/Peercoin-era wallets). Keep BDB major version matched
    across platforms that must open the same wallet.dat.
  * Native Linux builds: see doc/build-unix.txt (Ubuntu 22.04/24.04/26.04).
  * Based on the RNRC compile-windows.sh flow adapted for POS names
    (posd.exe / pos-qt.exe / pos-qt.pro).
