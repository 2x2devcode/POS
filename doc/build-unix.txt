UNIX BUILD NOTES
================

Supported hosts (native Linux builds)
-------------------------------------
  Ubuntu 22.04 LTS (Jammy)
  Ubuntu 24.04 LTS (Noble)
  Ubuntu 26.04 LTS (Resolute) and newer

The source tree includes OpenSSL 1.1/3.x and Boost 1.70–1.83+
compatibility layers (src/openssl_compat.h, src/boost_compat.h,
updated src/bignum.h).

To Build
--------

  # Headless daemon
  cd src/
  make -f makefile.unix -j$(nproc)
  strip posd

  # Qt5 GUI
  # (from repository root)
  qmake USE_UPNP=- pos-qt.pro
  make -j$(nproc)

See readme-qt.rst for additional Qt options.

Dependencies
------------

 Library     Purpose           Description
 -------     -------           -----------
 libssl      SSL Support       Secure communications (OpenSSL 1.1 or 3.x)
 libdb++     Berkeley DB       Blockchain & wallet storage
 libboost    Boost             C++ Library (1.70+)
 miniupnpc   UPnP Support      Optional firewall-jumping support
 libqrencode QRCode generation Optional QRCode generation
 Qt5         GUI               pos-qt wallet

miniupnpc may be used for UPnP port mapping. Set USE_UPNP:
 USE_UPNP=-    No UPnP support - miniupnpc not required
 USE_UPNP=0    UPnP support turned off by default at runtime
 USE_UPNP=1    UPnP support turned on by default at runtime

libqrencode: Set USE_QRCODE=1 to enable.

Dependency install: Ubuntu 22.04 / 24.04 / 26.04
------------------------------------------------

  sudo apt-get update
  sudo apt-get install -y \
    build-essential libssl-dev libdb++-dev libboost-all-dev \
    libminiupnpc-dev libqrencode-dev \
    qtbase5-dev qtbase5-dev-tools qttools5-dev-tools \
    libqt5gui5 libqt5core5a libqt5dbus5 qtchooser

Notes:
  * Package "qt5-default" was removed after Ubuntu 20.04 — use
    qtbase5-dev + qtchooser instead.
  * On Ubuntu 24.04+ some libraries use the "t64" time_t transition
    package names; apt resolves libssl-dev / libdb++-dev correctly.
  * System OpenSSL 3.x is supported. Legacy SHA256_* APIs are allowed
    via -DOPENSSL_SUPPRESS_DEPRECATED in the makefiles.
